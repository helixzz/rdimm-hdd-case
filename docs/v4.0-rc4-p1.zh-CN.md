# v4.0-rc4-p1：六个侧孔局部屏蔽支撑

用户反馈两条长边共六个安装孔中的支撑难以取出。本次是 **RC4 几何的打印工艺补丁**，不改孔形、孔径、孔位或外壳结构，也不提高速度。孔内上半圆柱面设置为禁止生成支撑，其余自动支撑配置保留。适用于直径 3.6 mm 的 `pin-clearance` 光孔外壳，不适用于攻牙底孔替代件。

## 使用

使用交付包 `rdimm-v4.0-rc4-p1-P2S-print-projects.zip` 内第一盘 `rdimm-4.0-rc4-p1-plate-1-pin-clearance-P2S-PLA-Basic.3mf`，在 Bambu Studio 中**打开为工程**并保留配置。使用 P2S / 0.4 mm 喷嘴 / PLA Basic / 0.20 mm 标准层高、按层打印。重新切片后，可在预览中按线型检查：六个侧孔内部不应出现支撑或支撑界面。

不要把工程仅作为几何导入，也不要用 STL 代替此工程：STL 不含局部支撑涂色。不要关闭全部支撑，外壳卡扣等区域仍需要支撑。第一盘包含外壳和盖板；第二盘的上托盘没有设计或工艺变化，已有托盘及正在打印的托盘可以复用。

## 检查结果

- 原 RC4 切片的六个孔都存在支撑刀路；局部屏蔽后，六孔包围区域中的支撑刀路均为零。
- 288 个网格面设置为禁止支撑，每孔 48 个。用 Bambu Studio 2.8.2.61 保存、重新打开并切片后，涂色完整保留，切片无警告。
- 第一盘导回顶点和三角面索引完全相同；第二盘重存带来最大 0.000004 mm 的坐标序列化舍入，三角面索引相同。全局参数只变更配置名称。
- 原有 28 个关键支撑区域及 9 个活动间隙再次通过名义有限线宽刀路检查。
- 第一盘预计 **2 小时 4 分 39 秒、89.98 g**，比 RC4 减少约 **54 秒、0.12 g**；第二盘约 **1 小时 1 分 39 秒、34.71 g**。整套约 **3 小时 6 分 17 秒**，不含换盘、清理与装配。

本次改动消除的是孔中需要清理的支撑，**尚未实测无支撑圆孔顶部是否下垂、定位销是否顺畅插入**。不能据此承诺零风险、孔径精度或免工具托架全面兼容。下一只外壳先检查六孔，再决定是否沿用；已打印件不会因工艺文件改变而自动解决清孔问题，无需仅为此废弃重打。

保留圆孔是为了避免在赶工中同时改变孔形和打印工艺。若孔顶实际下垂导致定位销受阻，再单独评估带斜面孔顶的自支撑孔形，并重新核对安装接口。

## 复现与记录

先按 [RC4 说明](v4.0-rc4.zh-CN.md)生成配置工程，再运行：

```text
python src/prepare_side_hole_project.py --bambu <Bambu Studio 可执行文件>
python src/audit_side_hole_supports.py
python src/audit_v4.py --version 4.0-rc4-p1 --depth 7.5 --geometry-version 4.0-rc4
```

`src/block_side_hole_supports.py` 仅识别本项目原始排版的光孔上半圆柱面并写入 Bambu 支撑涂色；几何版本仍为 RC4。保存后的工程 SHA256 见 [切片报告](reports/v4.0-rc4-p1-slicing.json)。另见 [六孔刀路比较](reports/v4.0-rc4-p1-side-hole-audit.json)、[原支撑区域检查](reports/v4.0-rc4-p1-toolpath-audit.json)。完整配置工程及 G-code 留在本地交付包，仓库中的原 RC4 几何文件不含此工艺补丁。
