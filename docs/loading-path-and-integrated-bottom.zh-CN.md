# 装入路径复查与底层一体化评估

用户将橙色单槽试件放入此前打印的 v3.1 水蓝色外壳，发现上沿挡住托盘；掰动外壳放入后，试件与 SATA 避让隆起相碰，无法放平。下面区分实际观察、现有几何诊断和新结构的可行性。**本文没有交付新的可打印整盒，不要求继续掰壳、削轨或追加小样打印。**

## 两个问题

### 1. 正式托盘也缺少顺畅的垂直装入路径

托盘长度为 **143.2 mm**；外壳两端滑盖上沿伸入后，最上方入口的长度方向净开口约 **140.6 mm**，比托盘短 **2.6 mm**。单槽试件、正式底/中/顶托盘均不能在设计 XY 位置直接垂直放下。RC1 仍沿用了这些上沿，不能靠更换 RC1 外壳锁扣解决。

用每件 121 个高度位置复查，正式托盘在最终位置均无体积相交，却在经过上沿时发生相交。之前只确认装配终态和取放 DIMM 的局部路径，没有验证完整托盘进入外壳的过程，遗漏了这项可用性条件。

这不是对所有旋转/平移组合的数学不可装入证明；即使某种斜插动作可行，也不能视为已满足无需掰壳、直观逐层取放的目标。

仅在虚拟诊断模型中去掉两端上轨后，三种正式托盘的相同垂直路径均无相交。该结果说明入口结构是本次阻挡的原因；**不等于可以直接削掉实物导轨**，导轨原本还承担盖板捕获功能，需要连同盖板一起重设计。

### 2. 单槽试件不等于正式底托盘

橙色 `test-tray-1` 用于独立验证 DIMM 槽口和拨扣，没有正式底托盘的 SATA 凹区；其代码以 `bottom=False` 生成。正式 `tray-bottom-2` 则挖掉 X=0..7、Y=10.8..58.2、局部 Z=0..3.2 的避让空间。

把单槽试件放在底托盘的名义高度 Z=4 时，计算得到约 **134.62 mm³** 的相交落在 SATA 隆起区域；另有局部定位结构相交。正式底托盘在正确终态下相交为零。这解释了用户看到的放不平，但不能用单槽件的结果判定正式底托盘也有同样的终态 SATA 干涉。

试件用途此前说明不足。后续检查件必须明确区分“独立夹持测试”与“可装入旧外壳的配合件”，或者直接覆盖真实的外壳装入路径。

## 底层直接固定 DIMM：有可行性，值得作为 v4 方向

建议研究 **外壳内一体固定 2 条 + 中层托盘 3 条 + 顶层托盘 3 条 + 免工具盖板**。底层取消独立托盘，但保留 PCB 边缘承托、平面限位、向上防脱和可触及的释放结构；不是把内存松放在盒底。

| 方面 | 初步结论 |
|---|---|
| 容量 | 继续以 2+3+3、共 8 条为目标，不因省一层底板宣称可增容 |
| 零件数 | 理论上从 5 个主要件减为 4 个，省去独立底托盘 |
| 进入外壳 | 参考 DIMM 本身长 133.8 mm，小于当前入口；裸模块在两个底层设计位置的垂直路径初查均无相交 |
| SATA 避让 | 当前 PCB 底面 Z=7.0，隆起顶部也为 Z=7.0；PCB 的空白边缘可以布置在此高度，颗粒必须保持避让，不能直接降低到盒底 |
| 元件位置 | 本次参考模型的芯片包络从 X=8.6 起，SATA 隆起伸到 X=6.8；这只是参考几何，不推广为所有 DIMM 的保证 |
| 打印收益 | 有望去掉重复底板、底托盘凹区的清理与一次装配动作；新增固定座也消耗材料，仍需实际切片比较 |
| 盘数/时间 | 未确定。少一个零件不自动等于少一盘，也不证明整套更快 |

裸模块路径只检查了模块与现有外壳，尚不含新固定座、手指、装卸动作及三层系统。因此这里只能确认布局有空间基础。

## 不能简单把原底托盘并入外壳

现有拨扣设计要求先把托盘拿出再解锁，不能直接用于固定在壳底的槽：

- 现有底托盘两根弹臂按既定 1.5 mm 外拨时，都会与外壳发生约 **1.25 mm³** 的几何相交。
- 若直接将原托盘与盒底合并打印，弹臂底边会沿长度与盒底连接，改变其弯曲方式，不能继续按原单端弹臂评价。
- 底层处于深腔内，必须确保不用工具即可触及释放部位，不能以夹持住内存但取不出来作为成功。

这些问题需要重新布置底层固定座与释放方式，不能靠原托盘的布尔合并解决。

## 与上盖一起重设计

仅省去底托盘仍会留下中、上层托盘过不了上沿的问题。新结构应优先采用**开盖后入口完全让开的免工具盖板**，让两层托盘垂直取放。可以研究整体可取下的盖板；若保留滑动操作，内伸导向结构也必须能够让开装配口。继续保持 147 × 101.6 × 26 mm、原 HDD 安装位置及背板避让约束。

新版本交付前应覆盖：空/满载中上层托盘完整装入和取出、底层 DIMM 在壳内装卸及手指可达性、盖板闭合/打开、每层防脱与合理余量、SATA 背板和安装孔位、支撑识别/拆除、整盘排版及 Bambu 切片时间。仍需实物确认保持力和反复开合。

现有 RC1 整套和额外旧结构检查件先暂停追加打印；RC2 A 仅修复旧锁扣试件的下承托，不能解决本次托盘入口问题。此次保留已通过的单槽实际 DIMM 配合结果，未发布 v4 文件。
