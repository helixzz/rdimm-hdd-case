## 支撑拆除反馈

| 位置 | 用户实物评价 | 当前结论 |
|---|---|---|
| A 外壳锁扣 | 顺利拆除，容易施力，但支撑与保留部分粘接紧密，需小心发力 | 本件可拆，不能归类为轻松剥离 |
| B 固定槽 | 顺利拆除，但依赖技巧，需要用镊子撬 | 本件可拆，工具接近和操作简便性待改善 |
| C 活动扣 | 顺利拆除，但依赖技巧，需要用镊子撬 | 本件可拆，薄弹臂清理后的状态待确认 |
| D 底部凹区 | 较难拆除，尤其小圆点需要精密镊子找到缝隙 | 本件可拆，是后处理改进的首要问题 |

本轮只更新实物记录，未调整模型或切片参数。不能因本次成功而推定加大支撑间距、减少接触层等改动不会引入新的打印问题。

## 后续功能反馈与修正

A 的前沿有支点，但两侧没有下承托。CAD 复现了后部向下倾斜 0.5–5° 的无阻挡路径；完整外壳另有安装柱承托，同一路径会接触，不能将小样失效等同为完整外壳失效。原检查遗漏倾斜下落，已在独立 RC2 A 试件中加入对应反向检查和两侧下承托。RC1 文件保持原状。

C 固定力弱仍是开放问题。本次单槽可固定并正常装卸，不能由此确认携带、防振或跌落保持力；没有据主观力度直接加厚弹臂。两端约 1 mm 余量不改变最不利参考包络的上方 0.1 mm 叠放余量，也不推广至其他 DIMM 型号。
