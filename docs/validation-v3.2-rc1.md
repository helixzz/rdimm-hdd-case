| 位置 | 用户实物评价 | 当前结论 |
|---|---|---|
| A 外壳锁扣 | 顺利拆除，容易施力，但支撑与保留部分粘接紧密，需小心发力 | 本件可拆，不能归类为轻松剥离 |
| B 固定槽 | 顺利拆除，但依赖技巧，需要用镊子撬 | 本件可拆，工具接近和操作简便性待改善 |
| C 活动扣 | 顺利拆除，但依赖技巧，需要用镊子撬 | 本件可拆，薄弹臂清理后的状态待确认 |
| D 底部凹区 | 较难拆除，尤其小圆点需要精密镊子找到缝隙 | 本件可拆，是后处理改进的首要问题 |
