用户补充的 A 两端照片可见狭槽内残片，并明确确认残留**主要是 Support for PLA**。因此下一步不能只解决 PLA 支撑芯强度，也要解决专用接触薄片的可达性和剥离。照片不能确定每处残片的原始层号、确切断裂面或粘接力。

### 已确认并修正的工程遗漏

RC4 的 P1/P2 从真实外壳截取，因此同时带入侧孔和底孔；生成器对 `process` 试件关闭了局部禁支撑选择，遗漏了这四个孔。原检查仅覆盖 H32 的两个孔，没有覆盖 P1/P2。这是交付和检查覆盖的错误。

`src/evaluate_rc4_feedback.py` 在原配置工程的**未发布副本**上恢复 P1/P2 孔内局部禁支撑，保留网格、全局参数及其他对象设置，使用 Bambu Studio 2.8.2.61 重新切片。每件增加 265 个禁支撑面，切片无警告。结果与校验值见 [刀路复核记录](reports/rc4-feedback-bore-audit.json)：

- 原 H32 两孔无自动支撑；原 P1/P2 四孔均确有自动支撑刀路。
- 修正副本的全部 **6 孔**检查区域均无自动支撑刀路。
- 另外复核完整产品选择性双材料候选的 **6 个侧孔＋4 个底孔**，全部无自动支撑刀路。

原测试盘估算 3795.305 秒，修正副本 3738.242 秒。此处约 57 秒差异仅属于测试盘，不作为整套产品收益。检查数是刀路分段数（包含圆弧离散），不是支撑件数量。修正副本孔顶的打印质量尚未实测；H32 的实测成功不能替代 P1/P2 孔顶验证。

### 下一步设计筛选

1. **优先处理薄片本身的取出。** 当前上下接触层分开，PLA 芯脱离后薄片可能仍留在成品上。评估把专用薄片连接到可达的剥离边或可取出的连接片，使取出操作能直接作用于薄片；检查其与成品的材料分离及实际刀路连续性。此解释是结构推断，不是粘接力测量。
2. **固定端改变受力路径。** 评估更靠近接触区的受力点和开放的剥离出口，避免仅延长、加粗把手；同时保留 DIMM 承托面、3 mm 卡簧基座及装卸净空。
3. **C1/C3 针对残留改进，H32 保持。** 不用增加配合间隙掩盖全部残留，不默认减少接触层、冲刷量或取消擦料塔。
4. **先检查完整工程，再选少数试件。** 对完整八槽、四处顶盖限位及全部安装孔检查几何、材料刀路、拆除可达性，并比较整套时间、专用耗材与换料次数；实际剥离力和残留仍需实物复核。P1/P2 的小试件结果不足以直接批准整套填充工艺。

本次不发布新测试盘，不更改已发布标签或工程附件；完整版本仍为 v4.3。RC4 当前结构不能标为免工具拆净、免后处理已通过。

## RC5 实物反馈：2026-10-05

- P1、H32：用户观察没有明显问题；延续 3.2 mm 孔及对应孔内禁支撑。不据此宣称完整外壳强度、全部底孔或所有硬盘托架已验证。
- B 独立永久压条：用户认为复杂、不好用、难保管且容易丢，暂停作为首选。
- 一体 DIMM 试件：用户称为“B 集成一体式”，发行版实际编号为 A；照片覆盖固定端和活动端。按结构记录，不将名称差异当作用户打印错误。用户明确确认散丝和碎块在打印完成、尚未碰支撑时已存在。因此至少发生了打印阶段失败，不能归咎于拆除技巧；具体脱落起始层及原因尚未知。
- C 组：用户写“C3、C3”，记录为两件 C 组反馈，未据此证明每个编号均被独立确认。比较容易拆净，但普通 PLA 在异材交界处有瑕疵。缺陷属于牺牲把手还是永久顶棚仍需区分。
- 照片私有，不上传。RC5 DIMM 支撑实测未通过；旧版几何/刀路连通检查不是打印稳定性证明。后续优先取消异材锁键和细梳齿，不继续单纯加粗把手。

用户建议可拆支撑体连同延伸把手全部用 Support For PLA、使用完整简单形状。新增 `src/evaluate_rc5_solid_support.py` 进行完整产品初筛：填平梳齿间隙，全部牺牲件采用专用材料，永久产品几何不变。20 件支撑无异材内部锁键，660 个名义取出姿态、整盒 512/242/1520/132 个姿态检查通过；两盘 Bambu Studio 切片无警告。

整套参考 **5 小时 28 分 37 秒，46 次换料，183.38 g**，其中 Support For PLA **26.86 g**（包含冲刷/塔；实际牺牲件专用材料仅约 0.77 g）。比 RC5 一体候选增加约 34 分钟；这只是初筛，不是更快或已证明更稳的方案。见 [切片报告](reports/rc5-solid-support-screen.json)。尚未进行该候选完整刀路、打印过程和剥离验证，不发布为可打印新版，也不覆盖旧附件。

全专用材料取消的是支撑内部 PLA/Support 连接，永久 PLA 与支撑的接触面仍存在；接触面积增大可能增加剥离力，不能承诺消除所有表面瑕疵。随后应优先检查宽底支撑的第一层是否稳定、顶棚首层覆盖与取出通道，再筛选把手高度及整套换料成本。

关于无支撑：两端局部顶棚/齿头即使最终成形，也可能经历临时残料承托和底面下垂；当前照片不是干净无支撑对照。短悬伸仍值得做局部候选，但应检查齿头下表面尺寸、DIMM 装卸及保持，不能直接推广整盒。通用桥接下垂机制参考 [Prusa 官方说明](https://help.prusa3d.com/article/poor-bridging_1802)；本产品可行性仍以其具体几何和实物为准。
